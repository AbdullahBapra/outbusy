# Image prompts: service pages

One set per service category (4 categories × 2 slots = 8 images). Every service page uses
its category's images. Same style rules as `home.md`, so the whole site reads as one series.

| Category slug | Services it covers |
|---|---|
| `ai-consulting` | AI automation audit, workflow audit, AI roadmap, custom AI solutions, workshops, white-label |
| `workflow-automation` | n8n, Make, Zapier, business systems, integrations & APIs, lead-to-CRM, documents, maintenance |
| `ai-agents` | RAG chatbots, voice agents, custom agents, WhatsApp/SMS, email agents, support AI, speed-to-lead, knowledge AI |
| `ai-websites` | AI websites, websites with voice agent / chatbot, landing pages, funnels, web apps & portals |

Negative prompt (if supported): `text, letters, numbers, logos, watermark, busy background, neon overload, purple, orange, stock-photo smile, plastic skin, distorted hands, extra fingers, lens flare, HDR`
